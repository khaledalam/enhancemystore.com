# enhancemystore.com

Marketing site for **Orders Analytics** (BigCommerce app), served free by GitHub Pages at https://www.enhancemystore.com.

- Plain static HTML/CSS with no build step: edit `index.html` and push to `main`, and it's live in about a minute.
- Custom domain: `CNAME` file + DNS at DigitalOcean (`www` CNAME → `khaledalam.github.io`, apex A records → GitHub Pages IPs).
- The app itself lives at https://orders-analytics.enhancemystore.com (separate repo/server).
